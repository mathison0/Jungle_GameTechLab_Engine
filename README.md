# ByeBye Solar System

### 게임의 목표:
지구에 붙어있는 제트팩을 조종해서 태양계를 벗어나는 것이 게임의 목표입니다.


### 게임 플레이 방법:
키보드 A, D키를 이용해서 왼쪽과 오른쪽으로 힘을 줄 수 있습니다.<br />
방해하는 행성들을 피해서 마지막에 도달하면 되는 게임입니다.


### 장애물(행성)의 종류:
플레이어가 행성에 닿으면 튕겨나며 일정 시간 동안 조종이 마비됩니다.
행성은 각각 다른 특성을 가지고 있습니다.

- **반발 행성:**<br />
접촉 시 플레이어를 튕겨내는 기본형 행성

- **밀어내는 행성:**<br />
주변의 플레이어를 바깥 방향으로 밀어냄

- **끌어당기는 행성:**<br />
주변의 플레이어를 행성 쪽으로 끌어당김

- **추적 달:**<br />
플레이어를 따라다니는 이동형 장애물

- **낙하 유성:**<br />
위에서 떨어지는 장애물로 예측이 어려움
