# Jungle GameTechLab Engine

크래프톤 정글 게임테크랩 과정에서 **1~14주차 동안 자체 게임 엔진을 만들어 온 기록**입니다.
각 주차 폴더는 원본 레포지토리를 `git subtree`로 병합한 것이라 **커밋 히스토리가 그대로 보존**되어 있습니다.
용량 관리를 위해 50MB 초과 파일과 빌드 산출물은 히스토리에서 제거했습니다. 발표자료는 각 주차의 `docs/` 폴더에 있습니다.

> 15주차 이후 진행한 **에픽 프로젝트**는 별도 레포지토리에 있습니다 → _(링크 추가 예정)_
